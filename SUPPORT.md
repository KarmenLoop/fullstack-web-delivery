# Support scope

Use issues for reproducible skill/documentation/example problems with sanitized evidence. Check the quickstart, platform matrix, example guide, and verification scope first. The agent host supplies tools, permissions, model access, and cloud preview behavior; this repository cannot grant them.

Installation instructions for another platform are not a full-flow certification. Physical devices, external services, commercial transactions, and public deployment require their own configuration and acceptance. No response-time or operational-service commitment is offered.

Modifications and derivative distributions are not supported or authorized by default. Request written permission at info@karmenloop.com. This does not restrict independent project outputs covered by the license exception.
