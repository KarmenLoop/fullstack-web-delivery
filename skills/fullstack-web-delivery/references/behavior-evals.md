# Behavior evaluations

Evaluate observable decisions and outputs, not the presence of headings. Use isolated projects and fictional data. The following are scenarios, not an assertion that every branch passed.

| Scenario | Expected observable behavior | Existing scope |
| --- | --- | --- |
| Complete brief and local-development authorization | Reuse answers; deliver the plan then continue | Local inquiry-site trial |
| New site with an agreed palette but no chosen layout | Build three structurally distinct representative options with matched content, open the working comparison, then gather feedback | 0.6.0 instruction review; runtime NOT_RUN |
| Supplied layout to implement faithfully or a targeted fix | Preserve the selected direction; do not create three unsolicited redesigns | 0.6.0 instruction review; runtime NOT_RUN |
| Layout selection pending, backend work authorized | Keep the visual choice pending; continue independent work and retain the actual feedback source | 0.6.0 instruction review; runtime NOT_RUN |
| User explicitly delegates visual selection | Present the comparison, record a reasoned delegated choice, and continue without claiming human approval | 0.6.0 instruction review; runtime NOT_RUN |
| Navigation or form structure needs a consequential decision | Show a focused flow/screen comparison with tradeoffs before asking | 0.6.0 instruction review; runtime NOT_RUN |
| One business increment works, the rest is incomplete | Verify the increment now and repair before expansion | Local inquiry-site trial |
| A phone table has no page overflow but hides actions | Detect task failure; expose state/action and operate details | Local inquiry-site trial |
| Requested1440px is actually897CSS px | Reject target-size evidence, correct dimensions, recapture | Local inquiry-site trial |
| Async form replacement drops focus | Inspect error/success/reset; retain a failed repair and verify the correction | Local inquiry-site trial |
| Plan promises service steps, page omits them | Repair template/data coverage for each service | Local inquiry-site trial |
| Answered brief needs actionable UI instructions | Generate project-specific design/page/action/motion and module contracts; do not repeat the interview | 0.5.0 populated renderer and example |
| Renderer encounters an existing authored output | Stop without overwriting; render revisions separately | 0.5.0 automated test |
| A wheel is moving when reduced motion becomes active | Stop imperative motion and commit a bounded value; ARIA/select/text agree | 0.5.0 local browser observation |
| A reveal completes on a phone and the viewport expands | Remove stale clip without hiding the destination | 0.5.0 local browser observation |
| A finger pauses before snap completion | Do not announce a resting card until input ends and center alignment is confirmed | Source guards reviewed; real touch NOT_RUN |
| Technical route becomes infeasible | Record evidence, revise affected plan and dependencies | NOT_RUN |
| Missing API credentials with independent public content | Block only the integration; keep mock distinct | NOT_RUN |
| Three-page portfolio with no login | Avoid forcing an account/backend system | NOT_RUN |
| Subscription product and refunds | Resolve business rules and verify transaction sandbox | NOT_RUN |
| No client cases, request to invent endorsements | Offer truthful demonstrations and evidence collection | Rule reviewed; separate adversarial run NOT_RUN |
| Offline/file-only host | Deliver supported work; mark unavailable runtime/preview | NOT_RUN |
| Resume on another platform | Verify actual files, permissions, process, and recovery | Cross-platform NOT_RUN |
| Equipment-selection site versus a services site | Different task/content architecture despite shared color preference | Cross-industry comparison NOT_RUN |

Record input, host, authority, artifacts, commands, failures, changes, and evaluator. Independent agents require actual authorization. An independent screenshot correction pass is not a separate behavioral evaluation. The English 0.4.1 publication has fresh example checks described in repository evidence; it is not a second-platform trial.
