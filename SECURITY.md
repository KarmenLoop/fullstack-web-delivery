# Security reports

Send a sensitive report to info@karmenloop.com with the affected version, component, impact, minimal reproduction, and a safe way to follow up. Do not open a public issue containing an exploitable private system, credentials, personal information, or client data. Do not test against systems you are not authorized to access.

The included website is a fictional loopback demonstration. It is not a production authentication service or a promise of a response-time/security certification. Source visibility and CI do not establish independent security acceptance. Only the latest published version is reviewed for new reports as maintenance capacity allows.

The repository excludes runtime accounts, cookies, private secrets, and databases. If a secret is accidentally exposed, its owner should revoke/rotate it through the relevant service; deleting text from the current branch does not remove its history.
