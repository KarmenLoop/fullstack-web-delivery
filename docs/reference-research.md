# Reference research and project translation

Research was conducted for a fictional SME digital-services business, not an objective ranking of every industry. Reference pages and official repositories were reviewed during the local trial on October 21, 2026. Different fields require new research.

| Primary source | Observed scope | Adopted principle | Project translation and limit |
| --- | --- | --- | --- |
| [Thoughtworks](https://www.thoughtworks.com/) | Official service content/navigation | Organize around client problems and method | Three relevant services, not a large consulting menu |
| [Work & Co](https://work.co/) | Official page and browser view | Strong type and clear service/project structure | Original service scenarios; no copied clients, imagery, or results |
| [Stripe](https://stripe.com/) | Official product presentation | Explain mechanisms visually | A site scene, a work board, and an automation chain |
| [Linear](https://linear.app/) | Official task/product hierarchy | Clear state and action priority | Staff work centers on finding and processing inquiries |
| [Apple Layout](https://developer.apple.com/design/human-interface-guidelines/layout) | Official guideline text | Hierarchy, grouping, alignment, progressive disclosure | Business first; detail follows the user's decision |
| [Apple Motion](https://developer.apple.com/design/human-interface-guidelines/motion) | Official guideline text | Purpose, interruption, restrained feedback, optional motion | Selected-state/layer feedback and reduced-motion alternatives |
| [Primer Brand](https://github.com/primer/brand) | Official repository/license | Marketing reading order and component responsibility | Reference only; not installed or copied |
| [Carbon](https://github.com/carbon-design-system/carbon) | Official repository/license | Operational density, tables, states | Reference only; phone task usability still required its own layout |
| [Radix](https://github.com/radix-ui/primitives) | Existing dependency and official source | Layer/focus primitives | Retain Dialog; test actual app behavior |
| [Motion](https://github.com/motiondivision/motion) | Existing dependency and official source | State/layer motion | Retain one motion dependency |

Primer Brand was reviewed as MIT and Carbon as Apache-2.0. They are not shipped implementations. Installed dependency versions and declarations are recorded in the lockfile and third-party inventory. A future adopter must check the actual selected version and materials rather than relying on this dated research.

No reference trademark, customer quote, portrait, recording, or customer result is used as proof of SENSU's work. The architecture illustration is AI-generated. There is no official Apple Web UI package in this project, no affiliation claim, and no multi-brand component skin assembled by installing every candidate.
