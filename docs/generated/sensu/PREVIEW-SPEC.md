# Preview specification

Project: SENSU Digital — enterprise site, interaction studies and motion atlas. Output language: English public example; use the client-requested language for new projects.

Scope: required.

Node 22.13+ below 23; npm ci, npm run setup, npm run dev. Default localhost port 4319; use a verified-free PORT for an isolated enhancement preview. Run production build and npm start separately. Track PID, cwd, port and mode; stop only the owned process. Open the actual browser and inspect CSS viewport and rendered controls. Keep public example, fixture tests and runtime secrets separate. Host without browser can provide source/build evidence but must mark UI operation NOT_RUN.
