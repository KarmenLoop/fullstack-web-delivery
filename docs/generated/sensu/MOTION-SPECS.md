# Motion choreography

Project: SENSU Digital — enterprise site and interaction studies. Output language: English public example; use the client-requested language for new projects.

Every adopted motion needs a purpose, trigger, linked state, duration/curve, interruption, keyboard/touch path, reduced-motion path and observable acceptance. Do not add all six studies to every project.

## I01

Press response 100–160ms; restrained page reveal; reduced-motion immediate. Native link supports open-in-tab and browser history. Acceptance: Open services using pointer and keyboard; verify URL, heading and Back.

## I02

Short progress/success transition; focus the result after form replacement; no ordinary-business confetti. Preserve entered data on error; retry with the same idempotency key; reset returns focus to first field. Acceptance: Submit, match reference in staff details and audit; test invalid fields, repeat, timeout uncertainty and reset focus.

## I03

Restrained button press; error appears without layout jump; reduced-motion instant. Keep email; do not expose secret or stack trace; allow retry after limit. Acceptance: Operate valid/invalid login and logout; anonymous admin API is rejected.

## I04

Drawer spring 360/30, interruptible exit; restore focus to the originating detail action. Conflict fetches latest version before retry; failed writes retain confirmed state; read-only role cannot mutate. Acceptance: Check two legal transitions, version conflict, audit actor/time, read-only 403 and dialog Escape/focus.

## I05

FLIP silhouette spring 360/30; check 200ms after 120ms; particles 420ms; reduced-motion no displacement/particles. Disable duplicate work; failed response retains review and provides retry; leaving study clears timer. Acceptance: Observe pending before success; inject failure, retry, reset and keyboard completion.

## I06

Ring 280ms; numeric value 240ms; color 240ms. Retarget from current values; no per-frame React renders. Uncheck reverses all feedback; textual final count remains available with reduced motion. Acceptance: Check/uncheck including rapid reversal; verify ring/count/text and zero/full states.

## I07

Spring 360/30; bounded 35ms ordering, reversed on gather; immediate reduced-motion layout. Repeat reverses existing motion; hidden cards are not focusable; toggle retains focus. Acceptance: Rapidly open/gather; verify stable order, labels and no clipped text at phone width.

## I08

Native scroll snap; prefer scrollend. Quiet fallback is only for browsers without it, requires released pointer/touch and center alignment within two CSS pixels; timeline draws 240ms after commit. Previous/next and Arrow/Home/End retain access; reduced-motion navigation scrolls instantly. Acceptance: Scroll and use Next/End/Home; confirm centered card and timeline agree after settle.

## I09

44px tick; velocity projection 180ms; spring 240/29; 0.18 elasticity; bounded index 0–6. New drag stops old animation; Arrow/Home/End and select provide alternatives; reduced-motion instant selection. If reduced motion becomes active during a spring, stop it and immediately commit the bounded target. Acceptance: Flick both ways and over bounds; interrupt settling; compare spinbutton, native select and selected-time text.

## I10

Circle begins at input coordinates or keyboard trigger center; radius covers farthest corner; 380ms ease; reduced-motion instant. Keep the actual origin even when the tab is below the panel; remove clipping after settlement so resizing remains safe. Last navigation wins; old layer inert and hidden from accessibility; no hidden focus targets. Acceptance: Operate all views, preference checkbox, rapid switch, keyboard Enter, Back/Forward and reduced motion.
